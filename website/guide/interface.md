# 界面一览

界面只有一层窗口：顶部是标签栏与地址栏，下面是网页或内置页面。所有内置页面都在这扇窗口里，不另开应用。

## 标签栏

- 标签显示网站图标和标题；正在播放声音的标签显示喇叭，点一下静音。
- 标签编号全局唯一（`tab-...`），关掉后不复用。
- 标签多到放不下时，左右出现箭头；滚轮可以横向滚。
- 标签可以置顶、分组；分组带颜色，在左侧标签栏模式下显示为一段。
- 右键标签可以复制标签信息、在新标签打开、静音、关闭其他标签等。
- 标签栏位置在 **设置 → 通用** 里切换：顶部或左侧。

## 地址栏

- 输入 URL 或搜索词；不是 URL 的文本交给当前搜索引擎。
- 左侧是后退、前进、刷新；右侧是下载、工作流、菜单。
- 打开内置页面时地址栏只显示页面名，不能输入。
- 正在录屏时，右侧出现红色「录屏」标记。

## 工作流

地址栏右侧「工作流」进入。这个页面同时是市场和本机工作流列表：

- **目录**：从 `xy200303/browserpilot-market` 拉取，按分类分组。点卡片看说明，点加号安装。
- **已安装**：本机已有的工作流；可以搜索、删除、导出。
- **导入**：填 GitHub 上的 JSON 地址，或选本机 JSON。
- **卡片**：名称、说明、参数数；点开是详情。

详情页有三组东西：

1. 说明与操作：打开画布、导出、删除。
2. 参数表单：按开始节点声明的变量生成；没有参数就显示「这次没有参数」。
3. 执行区：执行、交给 Agent、运行记录。执行中按钮变成「执行中」并禁用。

「交给 Agent」会把一段说明复制到剪贴板，里面带工作流名称和参数名；Agent 仍用 `workflow_run` 一次跑完。

## 画布

点「打开画布」进入节点图：

- 节点从左向右排；右边端点是出口，左边是入口。
- 判断节点每个分支一个端点，都不成立走 ELSE。
- 循环双击进入内部。
- 拖端点连线；选中连线按 Delete 删除。
- 点节点，在右侧改输入和输出；输入从上游产出里选。
- 右上角「导出」把整张图写成 JSON。

Agent 不在画布上点。它用 `workflow_write` / `workflow_update` 改图，用 `workflow_run` 执行。

## 运行记录

从工作流详情点「运行记录」，或菜单进入全部运行记录。

每条显示：

- 成功/失败图标、工作流名称、时间
- 失败时停在哪一步（节点编号）与错误
- 输出（`outputs`）和产生的文件路径
- 失败时的现场截图路径

运行记录按工作流筛选时只显示这一条工作流的运行。存储上限 200 条；界面列表最多 50 条。

## 下载

地址栏的下载按钮打开下载页：

- 下载中显示进度、已下载/总量、百分比
- 可以暂停、继续、取消、重试
- 完成后可以打开文件、打开所在文件夹、复制链接

网页触发的下载都会进这里，Agent 保存的媒体不会自动进列表（它返回本机路径）。

## 设置

设置分四栏：

### 环境

列出环境编号、名称、备注、窗口是否开着、有头/无头，以及这套环境里登录过的网站。可以新建、打开、改名、删除。

- 新建的窗口一定有头。
- 删除会清掉这套环境的 Cookie 和登录，默认环境不能删。
- 关掉窗口不会清登录；想收起就关窗。

### 抓包

当前标签的 HTTP 记录：方法、URL、状态、类型。正文和请求头里的 Cookie 只留在本机。可以导出 HAR。

### 通用

- 搜索引擎：必应、百度、Google、搜狗、DuckDuckGo
- 标签栏位置：顶部 / 左侧
- MCP 开关、监听端口（默认 39221）
- 批量并发上限（最大 3）
- 无头窗口上限（默认 3）

改完即生效。改端口会重开 MCP 服务并重写 `mcp.json`。

### 关于

版本号、项目说明、仓库入口。

## 遮罩与交接

- Agent 开始操作某个标签时，标签进入 `agent`，页面盖遮罩：「Agent 正在操作浏览器」+「接管」。
- 点「接管」→ `shared`，遮罩消失，任务不暂停。
- `page_handoff` 或工作流「交接」节点 → `handoff`，遮罩去掉，顶部留提示；下一步目标出现时重新上锁；没有定位时立即上锁。
- 锁定只影响当前标签，不影响同一窗口里的其他标签。

## 录屏

菜单里开始/停止录屏，或由 Agent 调 `screen_start` / `screen_stop`。录的是整扇窗口（标签栏、地址栏、网页），写成 mp4 放到 `videos`。只录有头窗口；一扇窗口同时只录一段。

和应用内「窗口录屏」不同，`page_record_video` 录的是页面里正在播放的视频画面，用于抓不到轨的流媒体。
